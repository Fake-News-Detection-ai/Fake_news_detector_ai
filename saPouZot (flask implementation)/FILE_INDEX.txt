1. app.py (3.7KB)
   Purpose: Flask backend server
   What it does:
   - Loads your trained ML model
   - Handles web requests
   - Makes predictions
   - Returns results as JSON
   - Serves the web interface
   
   When to use: This runs your web application
   How to use: python app.py


2. templates/index.html (22KB)
   Purpose: Frontend web interface
   What it does:
   - Beautiful UI with gradient design
   - Text input area for news articles
   - Analyze button
   - Results display with confidence scores
   - Progress bars for probabilities
   - Example buttons
   
   When to use: Automatically loaded by Flask
   How to use: Opens when you visit localhost:5000


3. requirements.txt (61 bytes)
   Purpose: Python package dependencies
   Contains:
   - Flask==3.0.0
   - scikit-learn==1.3.2
   - numpy==1.26.2
   - pandas==2.1.3
   
   When to use: Before running the app
   How to use: pip install -r requirements.txt


4. enhanced_fake_news_model_v2.pkl (NOT INCLUDED - YOU ADD THIS!)

   What it contains:
   - Trained Logistic Regression model

   Where to put: Same folder as app.py
