🐛 COMMON ISSUES & FIXES
------------------------

Issue: "Model file not found"
Fix: Make sure enhanced_fake_news_model_v2.pkl is in the same folder as app.py

Issue: "Module not found"
Fix: Run pip install -r requirements.txt

Issue: "Port already in use"
Fix: Change port in app.py (line 93): app.run(debug=True, port=5001)

Issue: "Page not loading"
Fix: Check terminal for errors, make sure you opened http://localhost:5000


💡 TECHNICAL DETAILS
--------------------

Backend:
- Framework: Flask (lightweight Python web framework)
- ML: scikit-learn (Logistic Regression)
- Vectorizer: TfidfVectorizer (50K features, bigrams)
- Calibration: Isotonic (for accurate probabilities)

Frontend:
- HTML5 (semantic markup)
- CSS3 (gradients, animations, flexbox, grid)
- JavaScript (vanilla, no frameworks)
- Design: Modern, responsive, accessible

Model:
- Algorithm: Logistic Regression
- Calibration: CalibratedClassifierCV (isotonic)
- Features: TF-IDF vectors (max 50,000)
- N-grams: (1, 2) - unigrams and bigrams
- Preprocessing: Lowercase, alphanumeric only
