--------------

- Error: Red gradient (#eb3349 to #f45c43)
- Background: White cards with subtle shadows
Font: Inter (modern, clean, professional)

DETAILED COMPONENT DESCRIPTIONS
--------------------------------

1. HEADER
   - Large, bold "AI Fake News Detector" title
   - Magnifying glass emoji (🔍)
   - Subtitle in lighter text
   - All white text on purple gradient background

2. INPUT AREA
   - Large textarea (minimum height ~180px)
   - Light border that turns purple on focus
   - Character counter at bottom right
   - Placeholder text guides the user

3. ANALYZE BUTTON
   - Full width, prominent
   - Purple gradient (#667eea to #764ba2)
   - White text, bold
   - Hover effect: slight lift + stronger shadow
   - Disabled state while analyzing (gray)

4. LOADING STATE
   - Spinning circle (purple)
   - "Analyzing article with AI model..." text
   - Only visible during analysis

5. RESULTS - VERDICT CARD
   FOR TRUE NEWS:
   - Bright green gradient background
   - Large ✓ checkmark
   - "LIKELY TRUE" in large text
   - "Confidence: XX%" below
   - White text throughout
   
   FOR FAKE NEWS:
   - Bright red gradient background
   - Large ✗ cross
   - "LIKELY FAKE" in large text
   - "Confidence: XX%" below
   - White text throughout

6. STATS CARDS
   - Two cards side by side
   - Light gray background (#f8f9fa)
   - Purple left border accent
   - Label in small caps
   - Large number in bold

7. PROBABILITY BARS
   - Two horizontal progress bars
   - Labels show percentage on right
   - TRUE bar: Green gradient
   - FAKE bar: Red gradient
   - Smooth animation when results load
   - Background is light gray

8. EXAMPLE BUTTONS
   - Small, pill-shaped buttons
   - Light background with border
   - Hover effect: purple border + purple text


ANIMATIONS & INTERACTIONS
--------------------------

Page Load:
- Header fades in from top
- Main card fades in from bottom
- Smooth, professional entrance

Button Click:
- Slight scale down on press
- Returns to normal on release

Loading State:
- Spinning circle rotates continuously
- Smooth transition in/out

Results Appear:
- Fade in animation
- Progress bars animate from 0% to final value (1 second)
- Smooth scroll to results section

Hover Effects:
- Buttons: Lift slightly + shadow increases
- Example buttons: Border changes to purple


RESPONSIVE DESIGN
-----------------
Mobile (< 768px):
- Stats cards stack vertically (not side by side)
- Text sizes adjust for readability
- Main card has less padding
- Everything remains functional and beautiful


COLOR PALETTE
-------------
Primary Gradient: #667eea → #764ba2 (Purple to Violet)
Success Gradient: #11998e → #38ef7d (Teal to Green)

Stats Background: Light gray (#f8f9fa)
